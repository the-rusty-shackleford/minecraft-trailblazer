# D-0004 — The comparison must finish the manoeuvre it claims to test

**Decision:** the real-client playtest applies lane bounds only before a drift starts,
then allows the complete fifty-tick hold and forty-tick release/boost observation.
The rugged lane is twenty blocks wide either side of its centre, accommodating the
existing open-loop steering weave through the whole terrain sequence. Steering keys
are all released between runs. Each Trailblazer run must observe both release and boost;
the Gradle task requires completion and no failure verdicts. Unknown run names and empty entries in a nonempty run selection fail. When both renderer tasks are selected, the photo booth runs after
the playtest rather than alongside it.

**Evidence:** the old real-client course ended the normal and interior runs nineteen
ticks into their drift, and the weave left its seven-block half-width at x=98.531,
before the drift pad at x=104. The command still returned success. Consequently those
traces contained zero boost ticks. After the boundary changes all four Trailblazer
runs reached release and observed forty boost ticks, peaking at 1.158 blocks/tick.

**Scope:** the measurements retain the protocol’s client driving authority, server collision
replay, terrain fit, steering, grip, damage, fuel and authored vehicle models. The
comparison under Iris/Complementary found no server move rejections or stuck reports.
The rugged runs had median movement 0.891 blocks/tick; eight zero-yaw steering samples
in the weave were airborne, none grounded. Movement distance includes vertical motion;
`driveSpeed` is logged separately so a drop cannot be mistaken for extra engine speed.

**Trade-off:** a wider generated lane takes more setup work but keeps the same steering
stimulus and terrain function. Tuning remains a play-feel choice; these
measurements provide a complete baseline for that choice.

The photo booth also requires its final completion marker. Under Complementary,
the red body panel renders in shade and failed the old absolute bright-red test
(eight matching pixels). Its paint predicate now uses relative channel dominance,
a brightness floor and a substantial visible area; the stock frame remains a
negative control and the painted frame must lose its blue. The brighter dashboard
needle predicate is separate. These are test changes; rendering and paint are unchanged.
