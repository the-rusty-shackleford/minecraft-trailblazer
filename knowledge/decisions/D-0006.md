# D-0006 — Approved repair policy and shared vehicle recovery

Rusty approved local implementation of cargo-preserving vehicle items, damaged-only
Mechanic Lift repairs and a paired recall fob. This partially supersedes D-0005's
frozen gameplay-profile rule: the only new profile field is `repair`, requiring
20 steel ingots for a full repair, proportional and rounded up for partial damage.
The historical released profile and artwork references remain unchanged. The art
import guard compares all prior fields to that reference and the new field to the
approved `reference/repair-policy.json`; art imports still cannot edit gameplay.

Version 1.8.0 bundles Vanilla Wheels 1.8.0, requiring protocol 5 on both peers.
Its shared implementation preserves cargo and damage on breakage and pickup, and
recalls the actual vehicle and its currently hitched trailer. Fuel shortfall costs
half the missing tank percentage in condition. See Vanilla Wheels D-0014 and README
for the full policy, duplicate prevention and normal persistence limits.

Existing artwork, physics, seats, interaction anchors and crafting costs remain as
before. Separately installed Metals and Materials is still required by the bundled
protocol. This is a local review candidate; publication and deployment are held.
