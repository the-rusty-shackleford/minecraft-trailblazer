# D-0005: Cosmetic refinement without deriving gameplay from art

Rusty requested a purely cosmetic vehicle-family refinement using Automobility as
the finish reference, explicitly authorizing edits to nfx-authored models while
preserving the originals and attribution. They approved the substantial second Pickup
prototype on 2026-09-16, after rejecting the first, barely visible pass.

Shaped bonnet, continuous dark arches, recessed rims, restrained cage and bumper chamfers, and coherent metal and rubber shades. The original knobby tyre geometry remains.

Keep the original source in `devtools/art/reference/`; the preview project is an
intentional derivative. This supersedes only D-0003's verbatim-art rule and
geometry-derived profile workflow. Existing identities and gameplay decisions stand.

`adopt.py --appearance-only` exports the body and wheel meshes. It requires the
current profile to equal the frozen `v1.6.0` profile before it runs; no profile or lang
file is generated. Wheel centring uses the existing simulation radius. Cube and polygon
UVs are both supported. Original opaque texture pixels, rig groups, road tyre geometry,
lamp faces, doors, seats and gauge elements are checked against the original project.

Speed, mass, handling, boost, fuel, damage, collisions, seats, camera anchors, interactions,
wheelbase/radius, hitch/coupler, storage, recipes, IDs and networking remain unchanged.
Preserve the separately held Vanilla Wheels collision/protocol work and Luminance's
interpolated movement of the original broad headlights.

Validation uses reproducible imports against real filesystem copies, semantic profile
comparison, real-server gametests, Blockbench views, and actual Iris/Complementary booths.
Judge joints, paint, dashboard, doors, storage, towing and night views at useful scale.
Matched frame-time runs compare original/current assets on the same held runtime.
These local checks do not establish independent multiplayer or group capacity.

This is held work. No new release, pack update or production replacement is authorized.
